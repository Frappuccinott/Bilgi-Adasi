## 1. Tasarım kararları

| Karar | Gerekçe (kaynak) |
|---|---|
| **Gazlar "ruh şişesi"nde:** kalın küresel cam, boynu eritilip kapatılmış (hermetik mühür). Renk verilmez. | Ortaçağda gaz toplanmazdı; ilk gaz toplama Hales 1727 (pnömatik tekne). Hermetik mühür = *sigillum Hermetis*. Gazların hepsi renksiz → renk yalancı olur. |
| **Gazlar siluetle ayrılır:** H₂ armut · O₂ nervürlü küre · N₂ basık soğan · CO₂ uzun boyun · CO isli küre | Renk tek başına bilgi taşımaz (Xbox XAG 103, gameaccessibilityguidelines). Siluet uzaktan ilk ayırt edicidir. |
| **Yakıt gazları (CH₄, C₃H₈) mesane kesesinde** (iki boy) | 18. yy'da gaz gerçekten kurutulmuş mesanelerde saklandı (Brownrigg 1765; 1747 maden grizusu). Yakıtları ayrı siluet ailesi yapar. |
| **Katılar albarello'da** (belli silindir küp, parşömen kapak + ip) — CaO kobalt, Ca(OH)₂ turkuaz | Albarello İslam dünyası kökenli ilaç küpü (Science Museum co78941, 12. yy Suriye). Diri kireç nem çeker → kapalı küp. |
| **Kireç taşı (CaCO₃) keten kesede**, düğümde örnek taş | Taş parçaları; kese yumruları içteki taşları gösterir. |
| **Su kalıp üfleme petek desenli şişede** (yeşilimsi cam) | Met 451716 / Aga Khan: 11.-13. yy İran petek desenli uzun boyunlu şişeler. Bitki külü camı yeşilimsidir. |
| **NH₃ basık küçük şişe, sıkı tıpa + lute** ("geyik boynuzu ruhu") | *Spirit of hartshorn*: boynuz damıtılarak elde edilen amonyak çözeltisi. |
| **Katmanlı mühür:** kap → tıpa → lute (bilgelik çamuru) → parşömen + ip → **düğümde balmumu mühür** → etiket | Lutum sapientiae, albarello parşömen kapağı (belgeli). "Mühürlü kap, içerik değişmez" mekaniğini görsel olarak doğrular. |
| **Mühürde formül:** her atom bir kabartma; **renk + şekil kodu**: H küre/beyaz · O halka/kırmızı · C küp/koyu gri · N piramit/mavi · Ca altıgen/açık yeşil | Oyunun element renkleri (05 §1) + CPK alışkanlığı; şekil ikinci kanal (renk körlüğü). |
| **Etikette** dönem adı + modern formül (Unity'de TMP, `Etiket_Yuzu`) | Eğitsel dürüstlük: "Diri kireç — CaO". C₃H₈ dönem adı kurgusaldır, oyunda belirtilecek. |

## 3. Elde tutma / envanter (Unity tarafına öneriler)

- **Viewmodel:** URP Render Objects özelliği, `ViewModel` katmanı, ayrı FOV 50-60°, duvara girmez (Unity 6 Render Objects dokümanı). Alternatif: Camera Stacking (Overlay kamera). Eldeki eşyada gölge kapalı.
- **Konum:** kameraya göre sağ +0,20, aşağı −0,13…−0,19, ileri +0,42…+0,55 m; içe −14…−18°. Ekran yüksekliğinin %25-35'i (Blender'da `el_testi.py` ile denendi).
- **Tek mesh, üç hâl:** dünya (Rigidbody + collider), elde (aynı mesh, fizik yok, ViewModel katmanı), ikon (bu mesh'ten render).
- **Fizik:** dik dursun → düz tabanlı Box/Convex collider, `centerOfMass` yükseklik × 0,25; Angular Damping 0,5-1,0; Continuous Speculative. Kütle 0,3-1,5 kg.
- **Sallanma:** eşya bob'u kamera bob'unun yarısı; ayarlardan kapatılabilir (XAG 117).
